# Version 0.1.2 Public-Site Delivery Model

## Decision

The public [Enterprise AI Delivery Pilot Guide](https://scott-wojan.github.io/enterprise-ai-sdlc/) is the primary consumption product.

The GitHub Pages site is the end-user interface. The repository remains the source of truth for canonical content, governance, backlog, review, traceability, provenance, and version history.

## Public product

The site provides:

- an immediate explanation of purpose, audience, and expected outcome;
- role-based starting points;
- a guided sequence through Understand, Prepare, Run, and Decide;
- action details with owner, expected time, output, steps, and stop condition;
- device-local progress tracking;
- an interactive Pilot Workbook with device-local saving and export;
- responsive navigation for mobile and desktop;
- no dependency on repository structure or Markdown navigation.

## Canonical source

The repository contains the detailed method behind the experience:

- normative requirements and adoption states;
- readiness and pilot procedures;
- Assisted Work and Bounded Change procedures;
- controls and decision rights;
- artifact definitions and templates;
- balanced measures;
- examples and facilitation guides;
- decisions, sources, traceability, and validation.

The site may simplify presentation but cannot weaken these requirements.

## Change rule

A content change begins in the canonical repository. When it changes user-facing purpose, sequence, action, stop condition, or workbook field, the site must be updated in the same release.

A site-only presentation change must not alter the method silently.

## Privacy and persistence

Progress and workbook entries remain on the reader's device. The current site does not send pilot records to a central service. Users may export the workbook as Markdown for placement in an enterprise-approved record system.

Do not enter secrets, credentials, sensitive prompts, or uncontrolled personal information into the workbook.

## Validation

The production build and hosted deployment must succeed before a site release is marked ready. The canonical repository continues to validate structure, terminology, and links.

## Known limitation

The first external enterprise pilot must validate navigation, comprehension, task completion, workbook burden, and mobile use with real participants. Findings should reduce friction without weakening canonical requirements.

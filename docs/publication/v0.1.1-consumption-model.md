# Version 0.1.1 Consumption Model

## Status

This Markdown-first consumption model has been superseded by the [version 0.1.2 public-site delivery model](v0.1.2-site-delivery-model.md).

The 22-page Pilot Guide remains maintained as plain-language source and validation material. Ordinary pilot participants now use the public responsive site rather than GitHub-rendered pages.

## What version 0.1.1 established

Version 0.1.1 added a human-centered content layer without replacing or weakening the version 0.1 method. It established:

1. Understand
2. Prepare
3. Run
4. Decide
5. Reference

It also consolidated active pilot records into one Pilot Workbook and moved detailed procedures, controls, roles, measures, identifiers, provenance, and traceability behind the primary path.

## What did not change

- Assisted Work remains the default starting mode.
- Bounded Change still requires every canonical lifecycle gate.
- Humans remain accountable for consequential decisions.
- Existing engineering, security, review, and release controls remain authoritative.
- Quality, control integrity, recoverability, and participant safety can block expansion.
- Approval for one scope does not transfer to another team, repository, use case, data class, or authority level.
- Platform-specific implementation guidance remains outside the vendor-neutral core.

## Known limitation

Independent enterprise participants have not yet completed a live usability study of the site. That validation should be captured during the first external adoption.

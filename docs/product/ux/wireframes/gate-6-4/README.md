# Gate 6.4 Responsive Structural System

## Status

Approved by the product owner and complete on 12 August 2026.

This package records the selected anchor views, the connected representative path, responsive and accessibility behavior, and the structural validation result. It does not approve final production architecture or change the production site.

## Representative user and job

A technology or delivery leader has been asked to introduce AI into enterprise software delivery. The person must understand the product, assess one exact pilot scope, respond safely to a hard stop, evaluate a later completed pilot across the full delivery system, and make a decision-ready leadership recommendation.

## Selected anchors

1. Public Home, desktop and mobile
2. Focused readiness response, desktop and mobile
3. Immediate hard-stop result, desktop and mobile
4. Completed-pilot evaluation, desktop and mobile
5. Leadership investment decision and readable output, desktop and mobile

The selected images and product-owner review records remain in this directory and its `explorations` folder.

## Connected path

The working prototype implements and validates this connected sequence:

1. Public Home
2. Adoption Journey
3. Apply the Playbook transition
4. Initiative Overview before interpretation
5. Focused readiness requirement
6. Validation error or saved draft
7. Interpreted hard stop
8. Initiative Overview in blocked readiness
9. Remediation open
10. Remediation verified while the prior decision still governs
11. Readiness output
12. Explicit later-scenario transition
13. Completed-pilot evaluation
14. Negative net-value evidence conclusion
15. Accountable restriction to Assisted Work
16. Leadership investment decision
17. Readable leadership output

## Screen-family separation

- Journey overview owns lifecycle position, current authority, aggregate blockers, and the next initiative action.
- Focused work owns one requirement, guidance, examples, response, evidence, and local interpretation.
- Gate decision owns an accountable decision for an exact scope.
- Reporting derives a readable outcome from source evidence and decisions and cannot alter them.

## Responsive contract

- Desktop reference width: 1440 pixels.
- Mobile reference width: 390 pixels.
- Mobile preserves the desktop semantic order in one column.
- Primary content does not require horizontal scrolling.
- Mobile has no permanent sidebar or detached consequence rail.
- Essential cause, consequence, permitted work, prohibited work, and next action remain in the primary reading path.

## Interaction and state annotations

- Save draft changes response status only and announces that no interpretation or decision occurred.
- Validation error moves focus to the error summary.
- Interpret response applies a deterministic restrictive rule and moves focus to the resulting screen.
- Hard-stop result immediately states the trigger, prior blockers, local correction effect, aggregate effect, permitted work, prohibited work, and remediation.
- Verify remediation changes remediation status to Verified for reassessment. It does not change authority or the prior gate decision.
- The later scenario explicitly represents elapsed organizational work and does not imply that navigation performed those actions.
- Record evidence conclusion changes the evidence conclusion only.
- Record authority decision changes AI participation for the exact scope only.
- Record investment decision changes funding disposition only.
- Reviewing or sharing the leadership output does not change any source record.

## Reading and keyboard order

1. skip link;
2. product and surface header;
3. optional menu;
4. restrained initiative context;
5. page eyebrow and H1;
6. consequence or decision summary;
7. evidence, guidance, or choices;
8. primary and supporting actions;
9. scope, authority, and source explanation;
10. prototype footer.

All core controls are native links, buttons, inputs, radios, checkboxes, text areas, and fieldsets. Visible focus uses a three-pixel high-contrast outline. Page transitions focus the new main region. Dynamic restrictive results use an assertive live announcement.

## Structural validation result

Static structure and implemented behavior pass the Gate 6.4 blocking criteria:

- no completion percentage or maturity score;
- no conflation of work, evidence, verification, decision, journey, or authority;
- hard stops cannot be averaged away;
- remediation does not restore authority;
- complete-system and total-cost evidence governs evaluation;
- evidence, authority, and investment decisions remain separate;
- the leadership output is readable without raw records;
- mobile retains the same meaning without horizontal scrolling.

Representative-human comprehension remains a Gate 6.7 activity. It is not fabricated as part of this record.

## Decision

The responsive structural system is approved as the implementation basis for the Gate 6 isolated prototype.

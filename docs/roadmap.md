# Product Roadmap

The roadmap represents the complete intended product. Milestones control implementation scope and validation order.

## Foundation milestone

Establish the repository context system, complete product architecture, governing principles, terminology, decision process, source ledger, issue schema, validation model and full epic catalog.

No substantive playbook procedure should be drafted until this milestone is approved.

## Version 0.1: Pilot Edition

Provide enough guidance to run controlled enterprise pilots at the Foundation, Assisted Work and Bounded Change states.

Expected scope:

- Normative core
- Readiness decision
- Enterprise foundation procedures
- Assisted-work procedures
- Bounded-change procedures
- Initial risk classes and controls
- Core artifact set
- Pilot selection, baseline and review
- Minimum balanced scorecard
- Two complete worked examples

Exit condition: a qualified enterprise team can run and evaluate a bounded pilot using repository content alone.

## Version 0.2: Governed Workflow Edition

Add specification-driven, multi-step delivery between explicit human and automated gates.

Expected scope:

- Intent capture and clarification
- Specification and planning
- Work decomposition
- Stage-level verification
- Context-management procedures
- Harness-improvement procedures
- Release evidence
- Production learning
- Additional worked examples

Exit condition: multiple teams can execute the governed workflow consistently without relying on its authors.

## Version 0.3: Selective Orchestration Edition

Add bounded coordination across delivery stages and specialized agents.

Expected scope:

- Orchestration eligibility
- Delegation boundaries
- Agent identity and authority
- Tool-access governance
- Inter-agent evidence transfer
- Operational telemetry
- Orchestration incidents
- Authority restriction and revocation

Exit condition: approved work types can be orchestrated with reconstructable decisions, controlled authority and reliable stop behavior.

## Version 0.4: Enterprise Operating Edition

Add organization-wide operation across different adoption states.

Expected scope:

- Portfolio and value-stream governance
- Mixed-state enterprise controls
- Exception management
- Periodic reassessment
- Cost and capacity governance
- Organization-wide enablement
- Cross-team context ownership
- Control ownership and lifecycle

Exit condition: the playbook supports scaled governance without forcing uniform autonomy.

## Version 1.0: Validated Enterprise Playbook

Reconcile earlier releases after field use, close material coverage gaps and complete scenario, traceability, accessibility and publication validation.

Version boundaries are planning hypotheses. Changes require a recorded methodology decision.
